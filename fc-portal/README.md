# 月見茶寮 直営FCステーション

直営本店からFC店へ渡す、現場用の専用サイトです。メールに混ぜない通達、本店で効いた改善、使う場所まで決めたPOP、キャンペーンの進め方、人気ドリンクのレシピを1か所に置きます。

試し見用の架空店です。実在のチェーンではありません。

## 開き方

リポジトリの `fc-portal/` を静的に配信するか、その場で:

```bash
cd fc-portal
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765` を開く。

| | |
|---|---|
| 店番 | `FC-014` |
| 合言葉 | `tsukimi` |
| 店 | 月見茶寮 橋本店 |

中身の差し替えは `js/data.js` だけです。POPの紙は `pops/` のSVGを印刷します。

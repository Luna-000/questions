# クラウドモニタ レイアウト原案

セルフカフェのモニタに出す、サブスクとビジネスプランの訴求原案です。店名、文章、金額、写真は仮で、あとから差し替えます。

- 縦モニタ: 1080×1920（18案）
- 横モニタ: 1920×1080（10案）
- 01–18 は文字組が中心。19–28 はイラストが中心で、案ごとに描き方を変えてある。グラデーション、線画、アイソメ、建築図、色面、幾何学、円柱、記号、図面、四種の描き方。
- 仮の店名: SELF CAFE
- 仮の金額（税込の体裁）: ライト 2,800 / スタンダード 4,800 / ビジネス 18,000（3席）

13番と18番は同じ割付です。色と文面だけ変えてあるので、モニタで交互に出せます。

全体は `png/00_一覧.png`。

## Canvaで編集する

文字と枠を触るなら **PPTX** を使います。PDFは見た目の確認用です。Canvaの環境によっては、PDFの文字が画像になって編集できません。

1. Canvaの「アップロード」から、向きに合うファイルを開く。
   - 縦: `pptx/クラウドモニタ_縦_Canva用.pptx`
   - 横: `pptx/クラウドモニタ_横_Canva用.pptx`
2. 開いたサイズがモニタと違うときは、カスタムサイズを縦 `1080×1920`、横 `1920×1080` にする。比率は縦 9:16、横 16:9。
3. 文字をクリックして、店名・文面・金額に差し替える。
4. フォントは次を選ぶ。
   - 見出し: Shippori Mincho（Medium）
   - 本文と価格: Noto Sans JP
   - 英字の小さいラベル: Cormorant Garamond
   - Shippori Mincho が無いときは、見出しを Noto Serif JP にする。
5. レイヤーの「写真」を削除して、同じ位置に写真を置く。灰色の面と PHOTO の文字が位置の目安。
6. 「QR」を削除して、登録用のQR画像を置く。
7. イラスト案の絵は、レイヤー名「イラスト」の一枚画像です。位置を動かすか、別の絵に差し替えられます。文字は絵とは別なので、そのままで編集できます。

仕上がりの見本は `png/` の各画像です。位置を合わせたいときは、そのPNGを背面に薄く置いて作業し、終わったら消します。

# scenery-window

PC作業中に絵画を流すビューア。

## いちばん簡単な開き方（Windows）

1. このフォルダ `scenery-window` を開く  
2. **`開く.bat`**（または `open.bat`）をダブルクリック

初回だけ画像を自動取得してから、ブラウザで開きます。  
サブモニターがあればそこに、なければメイン画面に出ます。

PowerShell からやる場合:

```powershell
cd パス\scenery-window
powershell -ExecutionPolicy Bypass -File .\open.ps1
```

## 操作

- **F** 全画面
- **I** 解説の固定
- **0–** 画家
- **← →** 次の絵
- **スペース** 一時停止

東京・神奈川・千葉・埼玉で、部屋や来歴が公開文に書いてあるカフェ、居酒屋、バーを調べる手帳です。手帳の点数やランキングはありません。個人の店と、2店舗くらいまでの店にしています。プロントのように同じ形が何軒もある店は入れていません。サザコーヒーは公式が16店舗と書いているので外しました。Googleマップの星は、2026年10月31日に店名の横へ出ていた数字です。浦和と川口のあいだに足した4軒は、2026年11月1日に見た数字です。4.0以上は「★4以上」で絞れます。4.0未満の店も、部屋や来歴があるので残しています。Roju Cafe は3.9でした。おすすめは、店の公開文に名前があるものだけです。カフェ51軒、居酒屋13軒、バー15軒です。東京は60軒、埼玉は12軒、神奈川は7軒です。浦和と川口のあいだには、西川口のサンドイッチ・ファクトリー、川口のロコピコ珈琲と茶色の小びん、蕨の喜酔を足しています。居酒屋とバーは、季節料理 赤津加、恵比寿商店、浅草昭和軒、笑壺、高円寺 動悸、波乃家 三代目、月逢、喜酔、Bar Bruder、Barどれすでん、BAR EVITA.、BAR WHITE OAK、Bar Ofen、Bar 貴、咲場923、Sake bar KoKoN を足しています。茨城・栃木・群馬は外しました。茶フェちゃきちも外しています。内装を店の文章が書いている店として、カフェ トロワバグ、Roju Cafe、Cozy Style COFFEE、カフェ CREATEA、BAR KAGE、cafe Le Havre、Polaris coffee、茶房コマを足しています。千葉は、この条件の店が今回はありません。浅草は、神谷バー、老舗の喫茶、ロッジ赤石を載せています。Café 晴蔵と、川越のきょうのごはん ゆるりCafe は、2026年10月31日のGoogleマップが閉業だったので外しました。

## 開き方

`index.html` をブラウザで開くか、このフォルダを静的サイトとして配信します。

```bash
python3 -m http.server 8765
```

スマートフォンでは、そのアドレスを同じ Wi-Fi から開きます。ホーム画面に追加すると、アプリのように起動できます。

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」または「アプリをインストール」

## できること

- カフェ、居酒屋、バーを切り替えて探す。しおりも、開いている種類だけを出す
- 店の公開文にあるおすすめ
- 場所の気分（森、水辺、古民家、高み、灯、旅先、鉱物、湯の町、社のとなり、レトロ）と、過ごし方（静か、長居しやすい、席広め、甘いもの、雰囲気重視、見晴らし、食事、朝から、夜まで）で絞る。その種類にない気分は出さない
- 電車、車、予約必須、季節営業、Googleマップの星が4.0以上、で絞る
- 地図で関東のどこにあるかを見る。ピンから詳細へ進める
- 住所のコピー、Googleマップ、公式ページ、電話
- しおり（この端末のブラウザだけに保存）
- 日本時間の日付で決まる「今日の一軒」

絞り込みはアドレスの `#` 以降に残るので、同じ条件を開き直せます。

## 情報の日付

営業時間は **2026年11月1日** までに見た公開情報です。各店に「公式の時間」「案内の目安」「当日確認」のどれかを付けています。案内が二つで違う店は「当日確認」にして、両方を書いてあります。出発前に、店のページで確認してください。バーは、神谷バーに加え、店のページに時間がある個人の店を載せています。銀座の BAR KAGE もその一つです。

カードと行き方には、駅からの徒歩を書いています。店の案内に分数があった店はその数字です。なかった店は、2026年10月31日に最寄り駅からの道のりを測り、分速80mで分数にしました。その分数は店が書いたものではありません。手帳に残しているのは、いずれかの駅から徒歩9分以内の店です。

地図のピンは、国土地理院の住所検索か、店が公開している座標です。番地まで取れなかった店は破線のピンで、町の位置を示します。正確な入口は、店の説明にある Googleマップ を使います。地図タイルは © OpenStreetMap です。

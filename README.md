# ソトガワ

関東1都6県で、ふだん使えるカフェ、居酒屋、バーを調べるための手帳です。点数やランキングはありません。駅の近くで食事や一杯ができる店に寄せ、山や湯の町、貸切のカクテルバーは外しています。おすすめは、店の公開文に名前があるものだけです。カフェ24軒、居酒屋13軒、バー7軒です。

PC のブラウザでも、Android や iPhone のブラウザでも同じページが開きます。通信が入る場所なら、特別なインストールは要りません。

## 公開アドレス

ブラウザでそのまま開くアドレスです。ダウンロードは要りません。

https://htmlpreview.github.io/?https://github.com/Luna-000/questions/blob/cursor/sotogawa-pages-d480/index.html

## 開き方

`index.html` をブラウザで開くか、このフォルダを静的サイトとして配信します。

```bash
python3 -m http.server 8765
```

スマートフォンでは、そのアドレスを同じ Wi-Fi から開きます。ホーム画面に追加すると、アプリのように起動できます。

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」または「アプリをインストール」

## できること

- カフェ、居酒屋、バーを切り替えて探す。しおりも、開いている種類だけを出す
- 店の公開文にあるおすすめ
- 場所の気分（森、水辺、古民家、高み、灯、旅先、鉱物、湯の町、社のとなり、レトロ）と、過ごし方（静か、長居しやすい、席広め、甘いもの、雰囲気重視、見晴らし、食事、朝から、夜まで）で絞る。その種類にない気分は出さない
- 電車、車、予約必須、季節営業で絞る
- 地図で関東のどこにあるかを見る。ピンから詳細へ進める
- 住所のコピー、Googleマップ、公式ページ、電話
- しおり（この端末のブラウザだけに保存）
- 日本時間の日付で決まる「今日の一軒」

絞り込みはアドレスの `#` 以降に残るので、同じ条件を開き直せます。

## 情報の日付

街なかに残したカフェの営業時間は **2026年10月30日**、足したカフェと居酒屋とバーは **2026年10月31日** に公開ページを見てまとめた目安です。各店に「公式の時間」「案内の目安」「当日確認」のどれかを付けています。出発前に、店のページで確認してください。バーの茨城は、駅前で公式の時間まで辿れた店がなかったので載せていません。宇都宮のディプントは、金・土・日の時間が公式ページにありません。

地図のピンは国土地理院の住所検索です。番地まで取れなかった店は破線のピンで、町の位置を示します。正確な入口は、店の説明にある Googleマップ を使います。地図タイルは © OpenStreetMap です。

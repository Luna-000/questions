# ちょっとソト

関東1都6県で、日常の外側にあるカフェを調べるための手帳です。点数やランキングはありません。景色、建物、世界観がいつもの用事の延長ではない店を、出どころが辿れる範囲で26軒載せています。

PC のブラウザでも、Android や iPhone のブラウザでも同じページが開きます。通信が入る場所なら、特別なインストールは要りません。

## 公開アドレス

ブラウザでそのまま開くアドレスです。ダウンロードは要りません。

https://htmlpreview.github.io/?https://github.com/Luna-000/questions/blob/cursor/sotogawa-pages-d480/index.html

## 開き方

`index.html` をブラウザで開くか、このフォルダを静的サイトとして配信します。

```bash
python3 -m http.server 8765
```

スマートフォンでは、そのアドレスを同じ Wi-Fi から開きます。ホーム画面に追加すると、アプリのように起動できます。

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」または「アプリをインストール」

## できること

- 店名・場所・キーワードで探す
- 気分（森、水辺、古民家、高み、灯、旅先、鉱物、湯の町、社のとなり、レトロ）と都県で絞る
- 電車、車、予約必須、季節営業で絞る
- 地図で関東のどこにあるかを見る。ピンから詳細へ進める
- 住所のコピー、地図アプリで開く、公式ページ、電話
- しおり（この端末のブラウザだけに保存）
- 日本時間の日付で決まる「今日の外側」

絞り込みはアドレスの `#` 以降に残るので、同じ条件を開き直せます。

## 情報の日付

営業時間は **2026年10月30日** に公開ページを見てまとめた目安です。各店に「公式の時間」「案内の目安」「当日確認」のどれかを付けています。出発前に、店のページで確認してください。

地図のピンは国土地理院の住所検索です。番地まで取れなかった店は破線のピンで、町の位置を示します。正確な入口は「地図アプリで開く」を使います。地図タイルは © OpenStreetMap です。
